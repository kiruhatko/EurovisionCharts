# Дзеркало MBTI

Один статичний файл — [`index.html`](index.html), без збірки й залежностей. Тип особистості очима друга плюс самооцінка: 91 твердження за шкалою від −3 до +3, кімната з кодом на двох учасників, результат у стилі liquid glass.

Усі питання (обидва формулювання — «про друга» та «про себе») — у [`questions.md`](questions.md) і на екрані «Усі 91 питання» в самому застосунку.

## Як користуватись

1. Один учасник натискає **«Створити кімнату»** і надсилає код (або посилання) другові.
2. Другий відкриває сторінку й вводить код. Один обирає **«Я — друг»** (і «він/вона» про людину), інший — **«Я оцінюю себе»**.
3. Обоє проходять тест. Результат з’являється в обох, щойно завершить другий учасник.

Режим **«На одному пристрої»** працює без мережі: спершу людина відповідає про себе, потім передає пристрій другові.

Щоб потестувати наодинці, відкрийте дві вкладки (або два вікна) — кожна вкладка є окремим учасником.

## Що в результаті

- тип (наприклад `ENFP-A`), назва й опис, сильні сторони, «як такий тип дружить»;
- чотири дихотомії E/I, S/N, T/F, J/P та додаткова шкала стійкості A/T — у відсотках, із позначками «я» та «друг»;
- 19 дрібніших шкал (грані) усередині осей;
- радар із 8 полюсів, стек когнітивних функцій, межові шкали;
- порівняння двох поглядів: збіг літер, близькість оцінок, де думки розійшлися;
- повзунок «вага думок» — від самооцінки (0%) до погляду друга (100%); за замовчуванням 50/50.

## Як рахується

Кожне твердження має напрямок: згода тягне до першого полюса осі (E, S, T, J, A) або до другого. У кожній осі половина тверджень «прямі», половина «зворотні». Вісь = сума `відповідь × напрямок` / (3 × кількість) → число від −1 до +1 → відсоток. Тип «разом» береться зі зваженого середнього двох поглядів. Рівно 50/50 вважається другим полюсом (I, N, F, P, T).

## Як працює кімната

Власного сервера немає. Учасники обмінюються «знімками стану» (ім’я, роль, відповіді) через публічний сервіс [ntfy.sh](https://ntfy.sh): `POST` на тему `dzerkalo-mbti-<код>` і `EventSource` (SSE) із `since=all`. Повідомлення зберігаються там ~12 годин, тому:

- можна перезавантажити сторінку або пройти тест пізніше — стан відновиться; крім того, він кешується в `localStorage`;
- будь-хто, хто знає код, може прочитати відповіді; не вводьте нічого, що не готові показати.

Сторінка потрібна друзям лише щоб **завантажитись один раз**. Далі все йде через ntfy.sh, тож обрив тунелю чи вимкнений комп’ютер ведучого вже відкритим сторінкам не шкодить (хіба що їх оновити).

Щоб використати власний екземпляр ntfy, перед скриптом задайте `window.MBTI_RELAY = 'https://ntfy.example.com'`.

## Як дати друзям доступ на деякий час

**1. Надіслати файл `index.html`.** Друг відкриває його в браузері на комп’ютері (подвійний клік), ви обмінюєтесь *кодом кімнати*. Посилання `#room=…` між копіями файлу не спрацює, надсилайте саме код. Хостингу не потрібно, але на iPhone так не відкрити.

**2. GitHub Pages — найстабільніше, нічого не треба тримати увімкненим.** У репозиторії, в папці `docs/`, лежить копія `index.html`. У репозиторії на GitHub: *Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `ccr-9df3d560-sdora1`, папка `/docs` → Save*. За хвилину-дві сторінка буде за адресою `https://kiruhatko.github.io/EurovisionCharts/`. Вона публічна. Щоб прибрати: *Settings → Pages* → поверніть Source у *None* (або *Unpublish site*). Змінили `index.html` — скопіюйте його знову в `docs/`.

**3. З комп’ютера на Windows через тунель** (потрібен лише Python, [python.org](https://www.python.org/downloads/) або `winget install Python.Python.3.12`; розпакуйте архів і запускайте файл подвійним кліком):

| Файл | Що робить | Нотатки |
| --- | --- | --- |
| `start-ssh.bat` | тунель через localhost.run (вбудований у Windows SSH, без реєстрації) | перепідключається сам; кожне перепідключення дає **нове** посилання |
| `start-pinggy.bat` | тунель через Pinggy, порт 443 | безкоштовне посилання живе 60 хвилин, далі перепідключається саме |
| `start.bat` | тунель Cloudflare (`cloudflared` скачається сам) | у деяких мережах `api.trycloudflare.com` недоступний («failed to request quick Tunnel») |

Як користуватись: дочекайтесь у чорному вікні рядка `https://…` і **відкрийте це посилання самі та створіть кімнату там** — тоді запрошення, яке ви скопіюєте, буде публічним. Надішліть друзям запрошення або просто код кімнати. Якщо з’явилось `TUNNEL DROPPED`, старе посилання вже мертве: беріть нове з рядків нижче. Вікно має лишатись відкритим, а комп’ютер — не засинати. Скрипти віддають лише копію `index.html` і слухають тільки `127.0.0.1`.

Повідомлення `no tunnel here` на адресі `…lhr.life` означає, що цього тунелю вже немає (SSH обірвався або це посилання з попереднього запуску).

**4. Друзі в тій самій Wi-Fi мережі.** У папці з файлом (Windows: `py` замість `python3`):

```
python3 -m http.server 8000
```

Дайте друзям адресу `http://<IP-вашого-комп’ютера>:8000`. Ctrl+C зупиняє сервер.
