# Дзеркало MBTI

Один статичний файл — [`index.html`](index.html), без збірки й залежностей. Тип особистості очима друга плюс самооцінка: 91 твердження за шкалою від −3 до +3, кімната з кодом на двох учасників, результат у стилі liquid glass.

Усі питання (обидва формулювання — «про друга» та «про себе») — у [`questions.md`](questions.md) і на екрані «Усі 91 питання» в самому застосунку.

## Як користуватись

1. Один учасник натискає **«Створити кімнату»** і надсилає код (або посилання) другові.
2. Другий відкриває сторінку й вводить код. Один обирає **«Я — друг»** (і «він/вона» про людину), інший — **«Я оцінюю себе»**.
3. Обоє проходять тест. Результат з’являється в обох, щойно завершить другий учасник.

Режим **«На одному пристрої»** працює без мережі: спершу людина відповідає про себе, потім передає пристрій другові.

## Що в результаті

- тип (наприклад `ENFP-A`), назва й опис, сильні сторони, «як такий тип дружить»;
- чотири дихотомії E/I, S/N, T/F, J/P та додаткова шкала стійкості A/T — у відсотках, із позначками «я» та «друг»;
- 19 дрібніших шкал (грані) усередині осей;
- радар із 8 полюсів, стек когнітивних функцій, межові шкали;
- порівняння двох поглядів: збіг літер, близькість оцінок, де думки розійшлися;
- повзунок «вага думок» — від самооцінки (0%) до погляду друга (100%); за замовчуванням 50/50.

## Як рахується

Кожне твердження має напрямок: згода тягне до першого полюса осі (E, S, T, J, A) або до другого. У кожній осі половина тверджень «прямі», половина «зворотні». Вісь = сума `відповідь × напрямок` / (3 × кількість) → число від −1 до +1 → відсоток. Тип «разом» береться зі зваженого середнього двох поглядів. Рівно 50/50 вважається другим полюсом (I, N, F, P, T).

## Як працює кімната

Власного сервера немає. Учасники обмінюються «знімками стану» (ім’я, роль, відповіді) через публічний сервіс [ntfy.sh](https://ntfy.sh): `POST` на тему `dzerkalo-mbti-<код>` і `EventSource` (SSE) із `since=all`. Повідомлення зберігаються там ~12 годин, тому:

- можна перезавантажити сторінку або пройти тест пізніше — стан відновиться; крім того, він кешується в `localStorage`;
- будь-хто, хто знає код, може прочитати відповіді; не вводьте нічого, що не готові показати.

Щоб використати власний екземпляр ntfy, перед скриптом задайте `window.MBTI_RELAY = 'https://ntfy.example.com'`.

## Публікація

Підійде будь-який статичний хостинг, наприклад GitHub Pages із папки `mbti-friends/`. Обоє учасників мають відкрити одну й ту саму адресу (або кожен — свою копію файлу: код кімнати працює між ними).
